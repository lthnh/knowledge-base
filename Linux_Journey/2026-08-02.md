Today I try installing Fedora XFCE. Things go smoothly for the most part except two issues:
1. App can't open links in browser due to a regression (specifically Spotify, I can't log in).
2. Mainline kernel v7.1.5 makes battery control impossible for this laptop (Asus VivoBook X513EAN_A515EA).
The first issue is documented here. It is due to older DEs doesn't support certain startup mechanisms. This causes xdg-desktop-portal.service to fail. It is documented [here](https://github.com/flatpak/xdg-desktop-portal/issues/1983#issuecomment-4651275776).
The second issue can be reverted by using 6.x.x kernels. By default, Fedora keeps 3 kernels. This is enough but having to move down one line when trying to boot into Fedora is annoying. So instead, I set default index in grubby. This feels more clean, though.

To set 6.x.x kernel as default, I do:

```
sudo grubby --set-default-index=1
```

To confirm the default kernel has been set:

```
sudo grubby --default-index
```
