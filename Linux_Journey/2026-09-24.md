I have troubles installing Pcells for Skywater PDK for several days now. Today I finally found the solution.

First I want to use magic to do the layout. But since magic is an old application (around roughly 30 years now?), it really doesn't scaled well with HiDPI screen.

Another great option is KLayout. Installing the PDK is easy with salt package manager although it doesn't always work, sometimes it timeouts before it actually loads. Here are some more quirks I encounter:
- On the first startup, KLayout is configured as a viewer, *not* as an editor. To fix this, go to File > Setup > Editing Mode > Use editing mode by default.
- Pcells generation requires gdsfactory as a *package* (according to this [description from efabless](https://github.com/efabless/sky130_klayout_pdk)). At first I tried to use it as an *executable* and guess what, it obviously didn't work. Try installing as an system wide package is not possible due to recent PEP requirements to prevent pip from modifying system Python packages. The last solution is to create an virtual enviroment and point KLayout to this. I will describe details procedure below.

To start KLayout in a venv:
1. First create an venv with a Python version matching that embedded in Klayout. We can check this in KLayout by going to Help > About. The current version of KLayout we are using is 0.30.12 which uses Python 3.13.15. We can use uv from astral to do this.
2. Then modify KLayout env variables with Flatseal:

```bash
KLAYOUT_PYTHONHOME=/dev/null
KLAYOUT_PYTHONPATH=/home/thomasle/.venv/lib/python3.13/site-packages:/usr/lib/python3.13:/usr/lib/python3.13/lib-dynload
```

First, we disconnect KLayout from the system Python by setting `KLAYOUT_PYTHONHOME` to some non-existing location. Doing so will make the system encoding libraries become unavailable. We will need to add them (/usr/lib/pythonx.x) again in addition to packages path from venv. Also one more problem I encounter is `_opcode not found` when `import gdsfactory`. This requires adding `/usr/lib/pythonx.x/lib-dynload` to the Python path. With this the issue is resolved.
