I try installing slang-server - a SystemVerilog LSP server for OpenCode. I want to install from a package manager to easier update. I search around and found Arch AUR repo. So I create a Distrobox container with Arch image then install slang-server from AUR.

But to install from AUR, we need to install base-devel and git to clone paru - a pacman wrapper to install things from AUR.

After paru installation, slang-server can be easily added as `paru -S slang-server-bin`.
