## XOR Gate
For two-input configuration, this is called the *difference* gate. Its output will be true when the input codes are different from one another. In modern electronics, this type of gate found little use since this functionality is much easier to implement using AND and OR gates.

XOR gates with greater than two inputs doesn't implement difference function since it is made by cascade two-input XOR gates. These gate returns true when there is an odd number of 1s on the inputs.

n-bit XOR gates are useful for error checking and arithmetic.

## XNOR Gate
For two-input configuration, its output is true only when two inputs is equivalent to one another.
For n-input configuration, its output is the inverse of n-input, XOR gate (i.e. XNOR output true when there is an even number of 1s).
