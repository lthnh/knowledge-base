## Performance Analysis
For hardware accelerators, throughput is limited by either computation speed or memory bandwidth.
Peak throughput represents the theoretical maximum computing capability.

$$
\mathrm{P_{peak}} = \text{Number of MAC units} \times \text{Ops per second} \times \text{Frequency}
$$

Substained throughput represents the actual performance on load.

$$
\mathrm{P_{substained}} = \dfrac{\text{Number of operations}}{\text{Execution time}}
$$

Hardware accelerator utilization is

$$
\text{Efficiency} = \dfrac{\mathrm{P_{substained}}}{\mathrm{P_{peak}}}
$$
