What is throughput? It's the amount of operations performed in a unit of time.
What is latency? It's the time required to complete a single operation or process a single input from start to finish. Latency measures response time: $\text{Latency} = T_{\text{output}} - T_{\text{input}}$.

$\text{Throughput} \approx \dfrac{1}{\text{Latency}}$. This equation does not hold for batched or highly parallel systems.

AI latency consists of these components

$$
T_{\text{total}} = T_{\text{pre}} + T_{\text{transfer}} + T_{\text{compute}} + T_{\text{post}}
$$

Higher batch size may result in higher output, but potentially higher response latency.

We should define *measurement boundary*.
1. Accelerator-only latency: Start > Accelerator > End. This measures hardware execution time.
2. End-to-end latency: Input > Pre-processing > Data Transfer > Accelerator > Post-processing > Output. This measures actual application response time.

The recommended methodology is:
- Perform *warm-up runs*
- Use multiple measurements
- Report mean/median
- Report P95/P99 when appropriate
- Clearly define start/end points
- Control clock frequency and power mode
- Specify batch size and precision

Energy and power are also considered assessment metrics.
