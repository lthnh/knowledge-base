## Feedforward Neural Network
An AI network where information flows in one direction from input to output
Its structure has no cycles or loops, meaning each neuron layer feeds forward only to the next.
Key characteristic: each layer learns from the previous one but does not affect previous layers.
## Backpropagation
It is essential gradient descent. The neural network learning is finding the local/global minima. Finding the local minima is easy but the global minima is tough.
The minima here belongs to the loss function. The loss function's parameters are the model's parameters (weights and biases) with respect to the desired outputs.
So, training the network is actually finding the local minima that minimizes the loss function.
